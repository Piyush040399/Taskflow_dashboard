# TaskFlow Dashboard

A responsive Task Management Dashboard built with React, React Router DOM, JavaScript (ES6+), Plain CSS, and the JSONPlaceholder REST API.

The application allows users to view, add, update, complete, and delete tasks while handling loading, error, and empty states.

# Tech Stack

- React
- JavaScript (ES6+)
- React Router DOM
- Plain CSS
- Fetch API
- JSONPlaceholder REST API
- Vite

# Steps to setup project in local

1. Clone the GitHub Repository
git clone <your-github-repository-url>

2. Navigate to the Project Directory
cd taskflow-dashboard

3. Install Dependencies
npm install

4. Start the Development Server
npm run dev
